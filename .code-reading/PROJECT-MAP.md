## Feature interaction graph

```text
cli-and-lifecycle (main.c)
  -> extension-discovery (extension.c: discover/find/describe)
  -> protocol-codec (protocol.c: parse/validate/serialize)
  -> x11-frontend (x11.c: open/draw/lookup/paste)
  -> input-editing (text.c + util.c UTF-8)
  -> extension-transport (extension.c: spawn/queue/flush/read/reap/close)
  -> setup-check (main.c: read_description/run_setup)
clipboard-capture (daemon.c + store.c)
  -> clipboard-adapter (clipboard/extension.c: forward QUERY/EXECUTE)
  -> extension-transport (same child protocol, via core)
  -> x11-frontend (daemon owns CLIPBOARD selection; core pastes via CLIPBOARD)
snippets (snippets/extension.c)
  -> extension-transport (same child protocol, via core)
  -> x11-frontend (holder owns CLIPBOARD; requestors read via CLIPBOARD)
  ~> clipboard-capture (holder ownership triggers daemon best-effort capture)
```

Ordering assumptions: discovery before UI; describe before query session;
`QUIT`/close before exit (currently `QUIT` never sent — known gap);
daemon explicitly started by user, never auto-started by core/extension.

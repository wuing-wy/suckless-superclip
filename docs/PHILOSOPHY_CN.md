# 设计哲学

[English](PHILOSOPHY.md)

## 专注的前端

superclip 处理所有命令共有的交互：打开面板、编辑查询、显示文本结果，以及执行选中的动作。
需要时启动，交互结束后退出。

## 独立的扩展

每项功能都是一个使用简单文本协议的可执行文件。扩展自行决定如何搜索、排序和处理结果，
也可以使用任何语言编写。这样，功能不依附于前端，也容易替换。

普通 GUI 流程中，只有用户选中扩展后才会启动它。`superclip setup` 是显式检查，会运行每个
扩展的自描述和 setup 接口。如果某项功能需要在两次面板调用之间保存状态，相关服务由该扩展
负责，何时启动则由用户决定。剪贴板历史就是这种模式。

## 可预期的行为

界面由输入框和平面结果列表组成，全程使用键盘操作。配置写在 `config.h` 中，并在编译时生效。

设计要求协议记录、结果数量、查询和持久历史都有固定上限，同时保证合法 UTF-8 和按 Unicode
字素簇移动光标。当前实现与这些要求之间的已知差距记录在
[PROGRESS.md](../PROGRESS.md) 中。

## 用户管理会话

superclip 配合用户现有的 X11 会话工作。用户选择热键工具，也决定是否把扩展服务加入会话启动。
`superclip setup` 会列出扩展建议的命令，供用户检查并自行应用。
